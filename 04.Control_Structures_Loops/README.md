# JavaScript loop assignment solutions

All 66 exercises from the [assignment](https://github.com/codinggita/CGxSU_Semester_1/blob/main/Semester_1/javascript_for_backend(sem_01)/sem_01/04.Control_Structures_Loop/Assignement.md) have standalone JavaScript solutions.

| Folder | Exercises |
| --- | --- |
| Part-1/For-Loop | 10 |
| Part-1/Break | 5 |
| Part-1/Continue | 5 |
| Part-1/Reverse-For-Loop | 10 |
| Part-1/Nested-For-Loop | 16 |
| Part-2/While-Loop | 10 |
| Part-3/Do-While-Loop | 10 |

Run a file from this directory with Node.js:

```bash
node Part-1/For-Loop/Q-01.js
node Part-1/Break/Q-02.js
node Part-2/While-Loop/Q-01.js
node Part-3/Do-While-Loop/Q-10.js
```

Change the sample variables at the top of each file to try different inputs.
No npm packages are required. The password exercise reads terminal input;
its sample password is `javascript123` and it allows at most five attempts.

## Notes on the questions

- The source labels its last two nested-loop questions as 16. Pascal's triangle is saved as Q-15.js, and the border matrix is Q-16.js.
- Reverse binary Q-08 corrects the source example: 13 is 1101 in binary, so its reversed digits are 1011.
- Reverse Fibonacci Q-05 prints exactly 15 terms, starting at 377 and ending at 0.
- For-Loop Q-05 treats the second-largest value as distinct from the largest value.
- Break Q-03 prints 14, the last number added when the sum first exceeds 100, and the resulting sum 105.
- Break Q-05 stops before printing 25, the first perfect square greater than 20.
- Nested Q-10 uses multipliers 1 through 10. Nested Q-11 and Q-16 use zero-based indices.
