# For loop assignment

Each question has a separate JavaScript file in its section folder. Change the sample variables at the top to try other inputs.

Run a solution with Node.js from this directory:

```sh
node For-Loop/Q-01.js
```

`Break/Q-02.js` uses browser `prompt()`. Paste that file into a browser's developer console to enter up to five passwords. The sample correct password is `javascript123`.

Notes on the questions:

- The second-largest solution finds the second-largest distinct number.
- In Break question 3, adding 14 makes the sum 105. The solution prints 13, the last number added before crossing 100, when the sum was 91.
- The first 15 Fibonacci terms are F0 through F14. The reverse solution starts at 377 and ends at 0.
- Decimal 13 is binary `1101`. Reversing those digits gives `1011`; the assignment's example has these swapped. Trailing binary zeros become leading zeros and are preserved.
- Nested question 10 uses multipliers 1 through 10, since the question does not specify a range.
- The two nested questions labeled 16 are saved as `Q-15.js` for Pascal's Triangle and `Q-16.js` for the border matrix.
- Matrix indices are zero-based. The value 2 overrides both border and inner values in the final question.
